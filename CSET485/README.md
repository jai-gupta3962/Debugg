# CSET485 – AI and Society Assignment 1

This folder contains the reproducibility materials for Assignment 1 (German Credit Data, roll number 0683).

## Reproduce the analysis

1. Use Python 3.10+.
2. Install the dependencies listed in `requirements.txt`.
3. Open `analysis.ipynb` in Jupyter Notebook or JupyterLab.
4. Run all notebook cells from top to bottom.

The assignment requires the last three digits of the roll number (`683`) as the train/test split seed and a 70/30 split. Keep the notebook's dataset and result-generation steps documented so figures and numbers quoted in the report can be regenerated.

## Files

- `analysis.ipynb` – analysis notebook
- `requirements.txt` – Python dependencies
- `data/` – dataset used by the notebook (if included)
- `results/` – generated tables and charts (if included)

Before submission, verify the notebook runs from a clean environment and that every value cited in the submitted PDF is generated by this notebook.
